# Личный кабинет успеваемости студента

## О проекте

«Личный кабинет успеваемости студента» --- Android-приложение для
просмотра учебных оценок, группировки их по дисциплинам, расчёта
среднего балла и отслеживания динамики успеваемости.

Проект основан на существующем проекте Android Studio. Базовая структура
сохраняется, предметная область и требования определяются новым
техническим заданием.

## Цель

- Создать приложение, позволяющее студенту:
- просматривать общую сводку
успеваемости; 
- просматривать дисциплины и оценки по каждой из них; 
- добавлять, редактировать и удалять оценки; 
- рассчитывать средний балл
по дисциплине и общий средний балл; 
- фильтровать и сортировать
оценки; - отслеживать динамику; 
- рассчитывать оценку для достижения
целевого среднего балла.

## Функциональность

**Обязательная:** главный экран со сводкой; список дисциплин; журнал
оценок; добавление, редактирование и удаление оценок; расчёт среднего
арифметического; проверка диапазона 2--5; пустые состояния.

**Дополнительная:** фильтрация по дисциплине, периоду и типу работы;
сортировка по дате или значению; динамика успеваемости; калькулятор
целевого среднего балла; подсветка дисциплин с низким средним баллом.

## Правила расчёта

В базовой версии все оценки имеют одинаковый вес. Средний балл --- сумма
оценок, делённая на их количество. Например, для оценок 5, 4, 3, 5
средний балл равен 4,25.

Формула требуемой следующей оценки:
`Требуемая оценка = Целевой средний балл × (Количество текущих оценок + 1) − Сумма текущих оценок`.

Если результат выходит за диапазон 2--5, приложение должно сообщить, что
цель недостижима одной следующей оценкой. При отсутствии оценок деление
на ноль не выполняется. Округление должно быть единообразным.
