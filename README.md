# Личный кабинет успеваемости студента

## О проекте

«Личный кабинет успеваемости студента» — Android-приложение для
просмотра учебных оценок, группировки их по дисциплинам, расчёта
среднего балла и отслеживания динамики успеваемости.

Проект основан на существующем проекте Android Studio. Базовая структура
сохраняется, предметная область и требования определяются новым
техническим заданием.

## Цель

Создать приложение, позволяющее студенту:

- просматривать общую сводку успеваемости;
- просматривать дисциплины и оценки по каждой из них;
- добавлять, редактировать и удалять оценки;
- рассчитывать средний балл по дисциплине и общий средний балл;
- фильтровать и сортировать оценки;
- отслеживать динамику;
- рассчитывать оценку для достижения целевого среднего балла.

## Функциональность

**Обязательная:** главный экран со сводкой; список дисциплин; журнал
оценок; добавление, редактирование и удаление оценок; расчёт среднего
арифметического; проверка диапазона 2–5; пустые состояния.

**Дополнительная:** фильтрация по дисциплине, периоду и типу работы;
сортировка по дате или значению; динамика успеваемости; калькулятор
целевого среднего балла; подсветка дисциплин с низким средним баллом.

## Текущий статус проекта

**Завершён Спринт 2 — «Модель данных и локальное хранение».**

На данном этапе реализован слой хранения данных на Room/SQLite:

- сущности `Discipline` и `Grade`;
- связь «одна дисциплина — много оценок» через внешний ключ `disciplineId`;
- DAO для обеих сущностей;
- `RoomDatabase` и базовая конфигурация;
- операции создания, чтения, изменения и удаления (CRUD) дисциплин и оценок;
- валидация допустимого диапазона оценок 2–5 на уровне слоя данных;
- тестовые данные для проверки приложения;
- подтверждено сохранение данных после закрытия и повторного запуска приложения.

Пользовательские экраны, расчёт среднего балла, фильтрация, сортировка,
динамика и калькулятор целевого балла запланированы на Спринты 3–5.

## Модель данных (реализовано в Спринте 2)

| Сущность    | Поля                                                              | Назначение              |
|-------------|-------------------------------------------------------------------|-------------------------|
| `Discipline`| `id`, `name`, `teacherName` (необязательно)                       | Учебная дисциплина      |
| `Grade`     | `id`, `disciplineId`, `value`, `date`, `workType`, `comment`      | Оценка по дисциплине    |

Связь: одна дисциплина может иметь много оценок (Discipline 1 — N Grade)
через внешний ключ `disciplineId`. Удаление дисциплины обрабатывается
осознанно: связанные оценки удаляются вместе с дисциплиной (каскадно),
либо удаление запрещается с понятным предупреждением — поведение
зафиксировано в реализации.

## Правила расчёта

В базовой версии все оценки имеют одинаковый вес. Средний балл — сумма
оценок, делённая на их количество. Например, для оценок 5, 4, 3, 5
средний балл равен 4,25.

Формула требуемой следующей оценки:

`Требуемая оценка = Целевой средний балл × (Количество текущих оценок + 1) − Сумма текущих оценок`

Если результат выходит за диапазон 2–5, приложение должно сообщить, что
цель недостижима одной следующей оценкой. При отсутствии оценок деление
на ноль не выполняется. Округление должно быть единообразным.
