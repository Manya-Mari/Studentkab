## 3. Замечания QA по правилам оценивания (закрыты)

1. Диапазон оценки — не был указан явно. Согласовано: целые значения 2–5.
2. Способ расчёта среднего — согласовано: среднее арифметическое всех оценок
   дисциплины, округление до 2 знаков.
3. Отсутствие оценок — согласовано: средний балл отображается как «—» (не 0),
   калькулятор динамики показывает пустое состояние с подсказкой.
4. Тип работы — согласован перечень: контрольная, лабораторная, домашняя, экзамен, зачёт.
5. Валидация даты — согласовано: дата не может быть в будущем.

## 4. Пользовательские сценарии и критерии приёмки

### US-01. Просмотр главной сводки
Сценарий: Студент открывает приложение и видит общую сводку по успеваемости.
Критерии приёмки:
- [ ] Отображается список дисциплин с количеством оценок и средним баллом.
- [ ] При отсутствии оценок по дисциплине средний балл = «—».
- [ ] При пустой базе отображается пустое состояние с призывом добавить дисциплину.
- [ ] Данные на главном экране соответствуют данным в списке дисциплин.

### US-02. Просмотр списка дисциплин
Сценарий: Студент переходит к полному списку дисциплин.
Критерии приёмки:
- [ ] Список отображает все добавленные дисциплины.
- [ ] Для каждой дисциплины видны название и число оценок.
- [ ] Доступны действия: открыть, редактировать, удалить.
- [ ] Удаление дисциплины запрашивает подтверждение.

### US-03. Просмотр оценок дисциплины
Сценарий: Студент открывает дисциплину и видит её оценки.
Критерии приёмки:
- [ ] Отображаются значение, дата, тип работы, комментарий каждой оценки.
- [ ] Отображается средний балл по дисциплине.
- [ ] При отсутствии оценок — пустое состояние с кнопкой «Добавить оценку».
- [ ] Список сортируется по дате (новые сверху).

### US-04. Добавление и редактирование оценки
Сценарий: Студент добавляет новую оценку или изменяет существующую.
Критерии приёмки:
- [ ] Форма валидирует значение в диапазоне 2–5 (иначе — сообщение об ошибке).
- [ ] Дата обязательна и не может быть в будущем.
- [ ] Тип работы выбирается из согласованного перечня.
- [ ] После сохранения оценка появляется в списке и пересчитывается средний балл.
- [ ] Редактирование предзаполняет поля текущими значениями.

### US-05. Динамика и калькулятор
Сценарий: Студент оценивает динамику успеваемости и прогнозирует средний балл.
Критерии приёмки:
- [ ] График динамики строится по датам оценок.
- [ ] Калькулятор рассчитывает средний балл с учётом гипотетической оценки.
- [ ] При отсутствии оценок отображается корректное пустое состояние.
- [ ] Результат расчёта совпадает с формулой из правил оценивания.
