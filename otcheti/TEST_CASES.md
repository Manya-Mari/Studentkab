
## Проект
**Название:** Личный кабинет успеваемости студента  
**Платформа:** Android  
**Технологии:** Kotlin, Jetpack Compose, Room  
**Документ:** единый набор тест-кейсов для всех 6 спринтов.

## Правила выполнения
- Тестирование проводится на актуальной сборке приложения в Android Studio на эмуляторе или устройстве.
- Используются только вымышленные тестовые данные.
- Для каждого тест-кейса после фактической проверки заполняются поля «Фактический результат» и «Статус».
- Статусы: **Не выполнен**, **Пройден**, **Не пройден**, **Заблокирован**.
- Тест-кейс нельзя отмечать пройденным до реального выполнения.
- Если обнаружена ошибка, записать шаги воспроизведения, ожидаемый и фактический результат.
