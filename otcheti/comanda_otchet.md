### Правила

-   Допустимый диапазон оценки --- от 2 до 5 включительно.
-   В базовой версии все оценки имеют одинаковый вес.
-   Средний балл --- среднее арифметическое.
-   Общий средний балл рассчитывается по всем внесённым оценкам.
-   При отсутствии оценок показывается понятное сообщение.
-   Недопустимое значение не сохраняется.
-   После изменения или удаления оценки средние значения
    пересчитываются.

### Планируемая модель данных

  -----------------------------------------------------------------------
Сущность                            Поля
  ----------------------------------- -----------------------------------
`Discipline`                        `id`, `name`, `teacherName`
(необязательно)

`Grade`                             `id`, `disciplineId`, `value`,
`date`, `workType`, `comment`
  -----------------------------------------------------------------------

Связь: одна дисциплина может иметь много оценок.

## 3. Реализованный функционал

### 3.1. Главный экран (список дисциплин)
- Список дисциплин, полученных из Room через DAO.
- Для каждой дисциплины отображаются название и число оценок.
- Элементы доступны для выбора (переход к экрану дисциплины).
- Обработка длинных названий без критического обрезания.
- Пустое состояние при отсутствии дисциплин.

### 3.2. Экран дисциплины (журнал оценок)
- Список оценок выбранной дисциплины: значение, дата, тип работы, комментарий.
- Сортировка записей по дате (новые сверху).
- Пустое состояние при отсутствии оценок с кнопкой «Добавить оценку».
- Кнопки добавления, редактирования и удаления оценки.

### 3.3. Форма добавления/редактирования оценки
- Поля: значение, дата, тип работы, комментарий.
- Валидация обязательных полей (дата, тип работы, значение).
- Проверка допустимого диапазона оценки: 2–5.
- Запрет даты в будущем.
- Понятные сообщения об ошибках под полями.
- При редактировании поля предзаполняются текущими значениями.

### 3.4. Удаление оценки
- Удаление выбранной записи с подтверждением.
- Обновление журнала и пересчёт данных после удаления.

## 6. Инструкция пользователя для демонстрации

1. Запустить приложение «Личный кабинет успеваемости студента».
2. На главном экране просмотреть список дисциплин и отображаемые средние баллы.
3. Выбрать дисциплину, чтобы открыть её журнал оценок.
4. Добавить оценку: указать значение от 2 до 5, дату, тип работы и при необходимости комментарий.
5. Открыть созданную запись для редактирования либо удалить её, подтвердив действие.
6. Использовать фильтры по типу работы и периоду, изменить порядок сортировки.
7. Просмотреть средний балл и динамику успеваемости.
8. Ввести целевое среднее в калькулятор и ознакомиться с рекомендацией приложения.
9. Повторно открыть приложение и убедиться, что сохранённые данные остались на месте.

Названия и расположение элементов следует сверять с фактической версией интерфейса, установленной для защиты.
